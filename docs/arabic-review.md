# Arabic copy and RTL review

Reviewed on 2026-10-09: all Arabic interface strings in `js/i18n.js`, Arabic search handling in `js/search.js`, and both semester labels, all seven module names, and all 53 resource titles in `data/resources.json`. I also checked the rendering paths in `js/components.js`, `js/module.js`, and `js/resource-list.js` for mixed RTL/LTR text. These are **suggestions only**; no source text or code was changed. Resource records are sample content, and any proposed module-name change should be checked against the department's official title before adoption.

Terms that already work well: `مقياس`, `السداسي`, `أعمال موجهة`, `أعمال تطبيقية`, `الدورة الاستدراكية`, Algerian month names `جانفي` and `جوان`, and the retained student abbreviations `TD` and `TP`. The Arabic plural forms in `js/i18n.js` fit the tested `Intl.PluralRules('ar')` categories. `js/lang.js` sets page direction to RTL; `js/components.js` isolates module codes, `js/module.js` isolates year headings, `js/resource-list.js` isolates markers and file sizes, and `js/search.js` isolates echoed search queries. Node's `ar-DZ` date and file-size formatters produced Western digits (`8 جانفي 2025`, `14 كيلوبايت`), as intended. The RTL items in the table are remaining review points, not evidence of a confirmed browser rendering failure.
