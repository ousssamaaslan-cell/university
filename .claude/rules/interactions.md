# Interactions

Every visible semester, module, search, filter, View PDF, and Download PDF control must work. Use native links and form controls where possible, with clear labels, keyboard access, focus handling, and empty/error states. Search and filters must not silently hide all content without an explanation. Honor reduced motion. Do not show a working PDF link when no file exists. Student pages show no admin control and no link to `/admin`; the maintainer's dashboard lives only there, and the doctor fails if a student page mentions it.
