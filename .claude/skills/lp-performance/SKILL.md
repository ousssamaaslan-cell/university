# lp-performance

Use the vendored `performance` and `core-web-vitals` skills and their supporting references. Read the target pages, catalogue size, and $ARGUMENTS. Establish a reproducible live baseline when possible. Inspect page load, list rendering, search/filter responsiveness, and unnecessary PDF fetching; make proportionate changes and compare under the same conditions. Distinguish synthetic metrics from field data. If the page or tools are unavailable, report hypotheses and blocked measurements in `docs/qa-report.md`.

Template-authored workflow; upstream source skills remain unchanged.
